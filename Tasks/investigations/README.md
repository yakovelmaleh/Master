# Investigation issues

This folder is the permanent index of investigated failures in the `Master`
project.

Each issue has its own folder named:

```text
<issue subject> <YYYY-MM-DD>/
```

Each folder contains a `README.md` describing the symptom, root cause,
evidence, decision, fix, validation, cleanup, and follow-up.
